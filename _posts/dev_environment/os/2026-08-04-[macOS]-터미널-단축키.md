## 출처

## 탭
 - Command + T : 새 탭
 - Control + Tab / Command + Option + 오른쪽 화살표 : 다음 탭 이동
 - Control + Shift + Tab / Command + Option + 왼쪽 화살표 : 이전 탭 이동
 - Command + W : 현재 탭 닫기
 - Command + N : 새 창 열기


## 화면 분할
 - Command + D : 화면 상하 나누기 (화면이 따로 놀지 않는 미러 형태)
 - Shift + Command + D : 분할된 화면 닫기
